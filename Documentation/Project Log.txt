Phase 5 : Create our Project Workspace

Cmd: pwd (To check present working directory)
Cmd: ls -la (Lists all items in the directory)
What are these files?

.bash_history
Stores previously executed commands.

.bashrc
Configuration for your terminal. Think of it as terminal settings.

.profile
Executed when you log in.

.cache
Stores temporary cache files.

.ssh
⭐ This is very important. It contains SSH keys and SSH configuration.



-> Create Project Directory
Cmd: mkdir EnterpriseBankingDataPlatform
Cmd: ls

-> Delete Directory 
Cmd: rm -rf EnterpriseBankingDataPlatform

-> We have to maintain proper structure so first git push your local Folder. 

On your local laptop:

Open the project in VS Code.

Make your first commit.
Create the GitHub repository.
Push it.
