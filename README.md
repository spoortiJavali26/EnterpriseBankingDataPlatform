# Enterprise Banking Data Platform

## Project Overview

Enterprise Banking Data Platform is an end-to-end data engineering project that demonstrates how enterprise banking transaction data can be collected, analyzed, transformed, stored, and visualized using modern data engineering tools and best practices.

The project integrates multiple public banking datasets, performs enterprise-style ETL using Python, stores curated data in PostgreSQL, and delivers business insights through Power BI dashboards.

The project is developed using a remote Linux server and Git-based version control to simulate an enterprise development workflow.

---

## Objectives

- Integrate multiple banking transaction datasets
- Perform enterprise-style data profiling and validation
- Design scalable ETL pipelines
- Generate AI-powered executive summaries using Google Gemini
- Build a dimensional data warehouse in PostgreSQL
- Create business dashboards in Power BI
- Follow professional Git and documentation practices
